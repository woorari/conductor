# Brand fonts

Figtree (weights 400–800) and Spline Sans Mono (weights 400–500), normal variable Latin webfont subsets. Served locally by the board; no runtime Google Fonts request. Glyphs outside these subsets use the system fallback.

Downloaded from the Google Fonts distribution on 2026-11-13:

- https://fonts.gstatic.com/s/figtree/v9/_Xms-HUzqDCFdgfMm4S9DaRvzig.woff2
- https://fonts.gstatic.com/s/splinesansmono/v13/R70BjzAei_CDNLfgZxrW6wrZOF2WX5KZmE-Z-lw.woff2
